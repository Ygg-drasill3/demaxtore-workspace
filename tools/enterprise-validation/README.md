# Enterprise Validation (Sprint 9)

Validation-only harness. **Does not modify** application FSMs, business logic, or workflows.

## Prerequisites

- **DeMaxtore backend** on `http://127.0.0.1:3001` (or set `EV_API_URL`)
- Postgres with migrations + seed (`yarn workspace @dmx/backend prisma:seed`)
- `DATABASE_URL` for DB probes
- **Do not** point `EV_API_URL` at port `8001` — that is the FreightIQ (uvicorn) service.

`EV_API_URL` is **required**. Example:

```bash
export EV_API_URL=http://127.0.0.1:3001
```

## Quick run (CI / dev, ~2 min)

```bash
yarn validate:enterprise
```

## Full run (staging)

```bash
EV_API_URL=http://127.0.0.1:3001 EV_SOAK_MS=86400000 yarn validate:enterprise:full
```

## Outputs

- `results/latest.json` — machine-readable metrics
- `docs/sprint-9-*.md` — eight reports + verdict (generated by `generate-reports.mjs`)

## Multi-instance test

Run 2+ backend processes against the same DB; confirm `job_executions` rows with `status=SKIPPED` and `metadata.reason=lock_held`.
