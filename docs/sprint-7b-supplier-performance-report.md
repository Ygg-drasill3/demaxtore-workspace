# Sprint 7B — Supplier Performance Report

## Growth score (0–100)

Combines invitations, quotations, selection/win rates, revenue attribution, and FreightIQ margin contribution.

## Classification

| Class | Criteria |
|-------|----------|
| Inactive | No recent quotes |
| Emerging | Early quoting activity |
| Active | Regular quotes or selections |
| Top Performer | High selection rate and revenue |

## Metrics

- Invitations received
- Quotations submitted
- Selection rate / win rate
- Revenue generated (proxy)
- Shipment volume
- FreightIQ revenue contribution

## API

`GET /api/growth/suppliers/performance`
