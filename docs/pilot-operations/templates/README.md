# Turkey Paid Pilot — Operational Templates

Printable / copy-paste forms for daily ops. **Not product code.**

| Template | Purpose |
|----------|---------|
| [`day0-checklist.md`](day0-checklist.md) | One-time gate before Customer #1 onboarding |
| [`transaction-control-sheet.md`](transaction-control-sheet.md) | Daily “where is it / who acts next” per transaction |
| [`friction-log.md`](friction-log.md) | Raw friction data → future Sprint 43 input |

**Playbook (reference):** [`../../turkey-paid-pilot-day0-customer1-operations-playbook.md`](../../turkey-paid-pilot-day0-customer1-operations-playbook.md)

**Usage:**

1. Duplicate templates into an ops workspace (or print Day-0 once).
2. Do **not** commit customer PII into this repo unless policy allows — keep working copies local/shared ops drive.
3. When Customer #1 starts, maintain **transaction control sheet** daily and **friction log** on every real problem.

**Next milestone:** Customer #1 live transaction — not Sprint 43.
